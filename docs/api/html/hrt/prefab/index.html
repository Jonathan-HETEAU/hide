Cache

The shared cache of the models, textures and shaders loaded by the prefabs.

CascadeParams

The parameters of a shadow cascade.

ContextMake

The context given to Prefab.make: a ContextShared, or the parent 2D or 3D object of the instance (converted to a new ContextShared).

ContextShared

The context shared by all the prefabs of a prefab hierarchy (but not by references): the root objects, the current parents during make, the source path, and the loading of the resources and baked data. In the editor, hide.prefab.ContextShared extends it.

ContextSharedBase

The context shared by all the prefabs of a prefab hierarchy (but not by references): the root objects, the current parents during make, the source path, and the loading of the resources and baked data. In the editor, hide.prefab.ContextShared extends it.

CrashTest

Editor debug only prefab that allow to test various crash situations in the editor Should never be loaded in a game

CrashTestObject

The object of a CrashTest prefab.

CullingContainer

A group of objects hidden when farther than cullDistance from the camera (always visible in the editor).

CullingContainerObject

An object hidden (with its children) when it is farther than a distance from the camera.

Curve

An animation curve: keys interpolated over time, used by the FX and the emitters (named property:component, such as scale:x).

CurveBlendMode

How a curve gets its values.

CurveHandle

A bezier handle of a curve key, relative to the key.

CurveKey

A key of a curve.

CurveKeyMode

How a curve is interpolated around a key.

CurveKeys

The keys of a curve.

Diff

Utility class to get the difference between two dynamics

DiffResult

The result of a diff between two values.

DynamicShader

Applies a shader given by its source path: a .hx shader class or a shader graph (.shgraph), with its parameters in props.

EditContext2

The context of the inspector of a prefab in the editor (Prefab.edit2): the scenes, the editor tools, and the editor services.

EditMode

How a reference can be edited in the editor.

GradientFollower

An object following a 3D object, scaled by the perspective (editor only).

Inclusion

Whether a pass query includes or excludes the passes.

Light

A PBR light (h3d.scene.pbr.Light): point, directional, spot, capsule or rectangle, with its shadows.

LightKind

The type of a light.

LightShadows

The shadows of a light.

Macros

The macros of the prefabs: they generate the serialization (@:s fields), copy and clone code of the prefab classes (buildPrefab, buildSerializable).

Material

Applies material properties to the materials of the parent object: the material of the same name (or materialName), or all of them. The properties can come from a material of a MaterialLibrary (refMatLib), with overrides.

MaterialLibrary

A library of materials, that Material prefabs can reference.

MaterialSelector

Selects material passes of the parent object (by pass name or blend mode), for the prefabs applying changes to the materials.

Model

A 3D model (source), with an optional animation.

Object2D

A prefab with a 2D transform, creating a 2D object (local2d). The base class of the 2D prefabs. The rotation is in degrees.

Object3D

A prefab with a 3D transform, creating a 3D object (local3d) in the scene. The base class of the 3D prefabs. Angles are in degrees.

OverrideProperty

A property of a referenced material library material overridden by a Material prefab.

PassQuery

A query of material passes, by name.

PrefabField

A serialized field of a prefab type (see Prefab.getSerializableProps).

PrefabFieldType

The type of a serialized prefab field.

PrefabInfo

A registered prefab type.

PrefabMeta

The metadata of a serialized prefab field.

PropDef

A property of a prefab.

PropType

The type of a property of a prefab (for the shader parameters and the generic properties editor).

Reference

True if the loaded source, or a reference inside it, creates a reference cycle

RenderProfile

A prefab containing RenderProps, applied to the renderer.

RenderProps

The properties of the renderer (h3d.scene.Renderer.props), by material setup, with the renderer effects (hrt.prefab.rfx.RendererFX children).

RenderPropsObject

The 3D object of a RenderProps prefab.

Resource

A prefab file resource (.prefab, .fx, .l3d...): load() returns its prefab, cached and reloaded when the file changes. Accessed with hxd.Res (hxd.res.Prefab).

SceneEditorAPI

The scene editor API available to the prefabs in the editor.

SelectedPass

A pass selected by a MaterialSelector.

SettingCategory

How an editor setting is shared between the inspectors.

Shader

Applies a shader to the materials of the parent object. The base class of the shader prefabs.

ShaderDef

A shader loaded by ContextShared.loadShader, with the initial values of its parameters.

ShaderDefCache

The shaders loaded, by path.

ShadowSamplingESM

Exponential shadow map sampling.

ShadowSamplingKind

The sampling of a shadow map.

ShadowSamplingMode

The sampling of a shadow map.

ShadowSamplingPCF

Percentage closer filtering sampling.

TreeChangedResult

What a prefab does when a child changed in the editor (see Prefab.onEditorTreeChanged).

Unknown

Allow openning prefabs with a type not found in the project, keeping the data unchanged.
