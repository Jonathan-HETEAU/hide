typedef ContextShared

package hrt.prefab

Available on hide_js

The context shared by all the prefabs of a prefab hierarchy (but not by references): the root objects, the current parents during make, the source path, and the loading of the resources and baked data. In the editor, hide.prefab.ContextShared extends it.
