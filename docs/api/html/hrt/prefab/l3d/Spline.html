class Spline

package hrt.prefab.l3d

extends Object3D

@:directlyUsed@:build(hrt.prefab.Macros.buildPrefab())@:autoBuild(hrt.prefab.Macros.buildPrefab())@:allow(hrt.prefab.l3d.SplineMesh)@:allow(hrt.prefab.l3d.SplineMeshSpawner)@:prefabIcon(HuiRes.ui.icons.prefab.spline)

Available on all platforms

A 3D curve through points, editable in the editor. It is sampled in world space to be evaluated at a progress t from 0 to 1.
