class ModelLibrary

package hrt.prefab.l3d.modellibrary

extends Prefab

@:build(hrt.prefab.Macros.buildPrefab())@:autoBuild(hrt.prefab.Macros.buildPrefab())@:access(h3d.prim.HMDModel)@:prefabIcon(HuiRes.ui.icons.prefab.model_library)@:prefabName("Model Library")@:prefabCategory("3D")

Available on all platforms

Bakes its children models into a single model and texture atlas, to render many instances with few draw calls (see Batcher).
