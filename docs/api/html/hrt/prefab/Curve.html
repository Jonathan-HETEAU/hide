class Curve

package hrt.prefab

extends Prefab

@:directlyUsed@:build(hrt.prefab.Macros.buildPrefab())@:autoBuild(hrt.prefab.Macros.buildPrefab())@:prefabIcon(HuiRes.ui.icons.prefab.curve)

Available on all platforms

An animation curve: keys interpolated over time, used by the FX and the emitters (named property:component, such as scale:x).
