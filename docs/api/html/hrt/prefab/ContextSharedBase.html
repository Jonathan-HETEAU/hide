class ContextSharedBase

package hrt.prefab

import hrt.prefab.ContextShared

extended by ContextShared

@:allow(hrt.prefab.Prefab)

Available on hide_js

The context shared by all the prefabs of a prefab hierarchy (but not by references): the root objects, the current parents during make, the source path, and the loading of the resources and baked data. In the editor, hide.prefab.ContextShared extends it.

Constructor

@:value({ isInstance : true, root3d : null, root2d : null })new(?path:String, ?root2d:Object, ?root3d:Object, isInstance:Bool = true)

Creates a context for the prefab file path, with its root objects.

Variables

@:value(null)current2d:Object = null

When make/instanciate is called, this contains the 2d object that should be used as a parent for the newly created object. Never modify this in the middle of a instanciate without restoring it after.

@:value(null)current3d:Object = null

When make/instanciate is called, this contains the 3d object that should be used as a parent for the newly created object. Never modify this in the middle of a instanciate without restoring it after.

currentPath:String

The path of the prefab file being made (the reference files change it).

@:value(null)findCache:Map<{}, Prefab> = null

Store result of non filtered Prefab.find during the make.

@:value(false)read onlyisInstance:Bool = false

Disable some checks at the prefab instanciation time. Used to initialize prefabs that don't need locals2d/3d like shaders

@:value(null)parentPrefab:Prefab = null

Parent prefab of the object if it was created as a reference.

@:value("")prefabSource:String = ""

The path of the root prefab file.

read onlyroot2d:Object

The root 2D object of the instance.

read onlyroot3d:Object

The root 3D object of the instance.

customMake:Prefab ‑> Void

When make() is called on prefab, it will instead call customMake on each child with current which can either intercept or call make() recursively.
