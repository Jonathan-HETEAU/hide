interface IEvent

package hrt.prefab.fx

import hrt.prefab.fx.Event

extended by Event, Event3D, SubFX

@:directlyUsed

Available on all platforms

An event of an FX timeline.

Variables

hidden:Bool

Hidden in the editor timeline.

lock:Bool

Locked in the editor timeline.

name:String

The name.

selected:Bool

Selected in the editor timeline.

time:Float

The start time, in seconds.

Methods

getDisplayInfo(ctx:EditContext):{loop:Null<Bool>, label:String}

getDuration():Float

Returns the duration, in seconds.

getEventPrefab():Prefab

Returns the prefab of the event.

prepare():EventInstance

Returns the event instance, or null.

setDuration(duration:Float):Void

Available on hide_js

Sets the duration (editor only).
