RGBAMerge

The texture graph node "RGBA Merge" (Channel): merges 4 grayscale images into a RGBA image. Inputs: R, G, B, A. Outputs: output.

RGBAMergeShader

Merges four grayscale textures in the channels of a texture.

RGBASplit

The texture graph node "RGBA Split" (Channel): separates a RGBA image into 4 grayscale images. Inputs: RGBA. Outputs: R, G, B, A.

RGBASplitShader

Extracts a channel of a texture as a grayscale texture.
