hrt.animgraph

..
nodes
AnimGraph

An animation graph made with nodes in the editor (.animgraph file): blends animations depending on parameters. Play it with getAnimation.

AnimGraphAnimatedObject

An object animated by an AnimGraphInstance.

AnimGraphInstance

A playing animation graph: a h3d.anim.Animation computing the bone transforms from the nodes.

AnimResolver

Returns the path of the animation to load for a path of the graph and a target object, or null to skip it.

BlendSpace2D

A 2D blend space (.bs2d file): blends the animations of its points depending on a 2D position.

BlendSpacePoint

A point of a BlendSpace2D: an animation at a position.

Edge

The connection of an input of a node.

EditorProviderContext

The context of the animation preview of the editor.

Macros

Builds the animation graph nodes from their @:input and @:output fields.

Node

A node of an animation graph. The fields with @:input and @:output metadata are its inputs and outputs, and the @:s fields are saved.

NodeAnim

Plays a single node of an animation graph, for the previews.

NodeInputInfo

An input of a node.

NodeOutputInfo

An output of a node.

OutputType

The type of an input or output of an animation graph node.

Parameter

A float parameter of an animation graph, set at runtime with AnimGraphInstance.setParam.

Resource

An animation graph resource (.animgraph file).

SerializedEdge

A serialized connection between nodes.

Tools

Animation helpers.
