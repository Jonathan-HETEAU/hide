class OneToMany

package hrt.tools

@:directlyUsed

Available on all platforms

Represent a collection of One -> Many relationship, i.e Multiple Right elements can point to an unique Left element. For example, a Parent -> Children relationship can be modeled with this, or a Output -> Input in a shadergraph.

Constructor

new()

Creates an empty collection.

Methods

clear():Void

Removes all the relations.

getLeft(r:Right):Null<Left>

Returns the left element of a right element, or null.

insert(l:Left, r:Right):Void

Add a relation in the collection. If the right element already has a relation, it will be removed and replaced by this one.

iterAll():KeyValueIterator<Int, Iterator<Right>>

Iterates on the left elements and their right elements.

iterRights(l:Left):Iterator<Right>

Iterates on the right elements of a left element.

removeLeft(l:Left):Void

Removes the relations of a left element.

removeRight(r:Right):Null<Left>

Removes the relation of a right element. Returns its left element, or null.
