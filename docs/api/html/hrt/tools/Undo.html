class Undo

package hrt.tools

Available on all platforms

An undo history of actions.

Static methods

staticactionFromActions(actions:Array<Action>):Action

Returns an action applying several actions (reverted in reverse order).

Constructor

new()

Creates an empty history.

Methods

canRedo():Bool

Tells if there is an action to redo.

canUndo():Bool

Tells if there is an action to undo.

getCurrentUndo():Any

Return the current active undo function (i.e. the one what would be executed if when calling Undo)

isDirty():Bool

Tells if an action with data changes was applied since the last markClean.

markClean():Void

Marks the current state as saved.

mergeWithLast(action:Action):Void

Merge action into the action that was just recorded : action is applied immediately, and is then undone and redone together with it (redo : recorded action then action, undo : action then recorded action). Must only be called from onRecord.

dynamiconAfterChange():Void

Called after each record, undo or redo.

dynamiconRecord(info:Null<Any>):Void

Called once when a new action is recorded (not on undo/redo), before onAfterChange. mergeWithLast can be called from here to apply the side effects of the recorded action in the same undo step.

record(action:Action, hasDataChanges:Bool, ?info:Any):Void

Record an action that has already been applied. info is an optional payload describing the action, passed to onRecord

redo():Void

Applies the next action again.

reset():Void

Clears the history.

run(action:Action, hasDataChanges:Bool, ?info:Any):Void

Applies an action and records it. hasDataChanges tells if it modifies the saved data.

undo():Void

Reverts the current action.
