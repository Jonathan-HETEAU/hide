class ShaderNode

package hrt.shgraph

implements IGraphNode

extended by Comment, Cond, IfCondition, Preview, Reroute, ShaderVar, SubGraph, Text, ShaderConst, ShaderCustomGlobal, ShaderGlobalInput, ShaderInput, ShaderNodeHxsl, ShaderOutput, ShaderParam, ShaderParticleInputs

@:directlyUsed@:autoBuild(hrt.shgraph.Macros.autoRegisterNode())@:keepSub@:keep

Available on all platforms

A node of a shader graph. Subclasses are registered automatically, and declare their inputs and outputs (getInputs, getOutputs) and generate their expressions (generate). The fields with @prop metadata are saved.
