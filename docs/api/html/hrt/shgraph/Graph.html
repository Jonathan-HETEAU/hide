resolveTypes():Void

Available on hide_js

Resolve the type of the dynamic (SgGeneric) inputs/outputs of every node from their connections, using the same rules as NodeGenContext.initForNode, and store them in ShaderNode.resolvedInputTypes/resolvedOutputTypes. When nothing is connected to a generic, it falls back to the most generic type of its constraint if one of its inputs has an inline value, else its ios are left null (unresolved).
