class RemoteConsole

package hrt.impl

@:directlyUsed

Available on all platforms

A simple socket-based local communication channel (plaintext and unsafe), aim at communicate between 2 programs (e.g. Hide and a HL game).

Usage in game (see also hrt.impl.RemoteTools):

var rcmd = new hrt.impl.RemoteConsole();
// rcmd.log = (msg) -> logToUI(msg);
// rcmd.logError = (msg) -> logErrorToUI(msg);
rcmd.connect();
rcmd.sendCommand("log", "Hello!", function(r) {});
