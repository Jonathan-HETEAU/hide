class ScenePreview

package hide.comp

extends Scene › Component

@:directlyUsed

Available on hide_js

A Scene that is specialised to load one prefab or mesh for preview. Stores its settings (model and render props) in the display state.

Set the preview object path and reload the scene. If path is a .prefab, this.prefab will be the loaded prefab If path is a .fbx, this.prefab will be a hrt.prefab.Model with it's source = path
