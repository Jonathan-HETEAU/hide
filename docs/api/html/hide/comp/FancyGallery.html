class FancyGallery<GalleryItem>

package hide.comp

extends Component

@:directlyUsed

Available on hide_js

A virtualized grid of item thumbnails with zoom levels, selection, renaming and drag and drop. The items are given by the getItems, getName and getThumbnail callbacks.

new(parent:Element, el:Element)

Creates a gallery in a fancy-gallery element (or a new one).
