class FancyTree<TreeItem>

package hide.comp

extends Component

@:directlyUsed

Available on hide_js

A tree view component of items of any type, with lazy loading, search, multiple selection, renaming, buttons and drag and drop. The items are given by the getChildren, getName and getIcon callbacks.
