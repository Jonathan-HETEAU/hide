Cell

A cell of a CDB table: displays and edits the value of a column of a line.

Cursor

The cursor and selection of a CDB editor, with the history of the positions.

CursorState

A saved cursor position.

DataFiles

The CastleDB sheets whose lines come from prefab files (dataFiles sheet property).

DataProps

Where a line of a CastleDB sheet with data files comes from.

Direction

A horizontal direction.

DisplayMode

How a CDB table is displayed.

Editor

The CastleDB editor component: shows and edits a sheet of the database, with cursor, undo, clipboard, search and filters.

EditorApi

The data access of a CDB editor.

EditorColumnProps

The editor properties of a CDB column.

EditorSheetProps

The editor properties of a CDB sheet.

FilterFlag

A kind of line shown by the editor filters.

FilterFlags

A set of FilterFlag.

Formula

A CDB formula: a function of the formulas file computing a number column from a line.

Formulas

The formulas of a CDB editor, loaded from the cdb.formulasFile hscript file. Each function taking a line of a sheet type is a formula for that sheet, or a validation function if its name starts with validate.

FormulasView

The script view of the formulas file, with the sheet types for the checker.

Line

A line of a CDB table.

ModalColumnForm

The form creating or editing a CDB column.

ObjEditor

A CDB editor of one object (all its properties) of a sheet type, stored in a file.

OptionalBackup

The empty optional values removed by Editor.cleanupOptionalLines, to restore them.

ScriptTable

The sub table of a script cell: a script editor.

Selection

A rectangle of selected cells. x1 is -1 when whole lines are selected.

Separator

A separator of a CDB table: a collapsible titled group of lines, which can be nested.

SheetAccess

The access to a sheet given to the formulas, as a global named after the sheet type.

SubTable

The table of a list, properties or polymorphic cell, shown under its line.

Table

A table of a CDB editor, showing the lines of a sheet.

UndoSheet

A sheet shown in the editor, as stored in the undo state.

UndoState

A state of the editor saved in the undo history.

ValidationFunction

A line validation function of the formulas file: a function whose name starts with validate.

ValidationResult

The result of a line validation function.
