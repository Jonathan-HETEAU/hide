Terrain painting shader: normalizes the surface weights.

The debug render mode of the terrain editor.

SetHeight

Terrain sculpting shader: moves the height towards a target height with the stroke strength.

SmoothHeight

Terrain sculpting shader: moves the height towards the average of its neighbors with the stroke strength.

StrokeBuffer

A render target accumulating a brush stroke on one terrain tile.

StrokeBufferArray

The stroke buffers of the tiles touched by a stroke.

SwapIndex

Terrain shader: replaces surface indexes in the surface index map.

TerrainEditor

The editor of a terrain prefab: sculpts the heights, paints the surfaces and deletes the tiles with brushes.

TerrainRevertData

The undo data of a surface change.

TileRevertData

The undo data of a tile change: its maps before and after.
