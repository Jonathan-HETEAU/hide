Extension

The registry of the views opening each file extension.

ExtensionDesc

A registered file extension.

ExtensionOptions

The options of a file extension.

FilterPathContext

The context passed to the Ide.filterPaths callbacks, to change the file paths found in the project data.

HTMLElement

An HTML element (Dynamic on HashLink).

HideGlobalConfig

The global settings of the editor, per user (the hide field of the global props.json).

HideProjectConfig

The settings of the IDE for a project.

Ide

The HIDE editor application: project, windows, views, layout, menus, dialogs and clipboard. The running instance is Ide.inst.

IdeCache

A cache of the IDE stored in the engine resource cache.

LayoutState

A saved layout of the IDE.

MaterialSetup

The material setup of the editor (forward renderer).

MessageKind

The kind of a message shown by Ide.globalMessage.

PbrRenderer

The PBR renderer of the editor: renders the highlight passes and the ui overlay pass.

PbrSetup

The PBR material setup of the editor.

Renderer

The forward renderer of the editor, with the editor passes.

ScreenOutline

Draws the outline of the highlighted objects.
