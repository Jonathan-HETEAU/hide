interface IGraphEditor

package hide.view

import hide.view.GraphInterface

extended by ShaderEditor, TextureEditor, GenericGraphEditor

Available on hide_js

The graph data edited by a GraphEditor: nodes, edges, add menu, serialization and undo.

Methods

addEdge(edge:Edge):Void

Adds an edge to the graph.

addNode(node:IGraphNode):Void

Adds a node to the graph.

canAddEdge(edge:Edge):Bool

Returns false if the edge can't be created because the input/output types don't match

createCommentNode():Null<IGraphNode>

Create a comment node. Return null if you don't have a comment node in your editor

createRerouteNode(edge:Edge):Null<IGraphNode>

Create a reroute node that can be inserted in the middle of edge. Return null if you don't have reroute nodes in your editor

getAddNodesMenu(currentEdge:Null<Edge>):Array<AddNodeMenuEntry>

currentEdge is not null it there is a link being created. You can use this information to filter the list of nodes in the output entry based on compatible types

getEdges():Iterator<Edge>

Returns the edges.

getNodes():Iterator<IGraphNode>

Returns the nodes.

getUndo():UndoHistory

Returns the undo history.

removeEdge(nodeToId:Int, inputToId:Int):Void

Removes the edge connected to an input.

removeNode(id:Int):Void

Removes a node from the graph.

serializeNode(node:IGraphNode):Dynamic

Returns the data of a node, for copy and undo.

unserializeNode(data:Dynamic, newId:Bool):IGraphNode

If newId is true, then the returned node must have a new unique id. This is used when duplicating nodes
