class PreviewSettings

package hide.view.shadereditor

import hide.view.shadereditor.ShaderEditor

@:directlyUsed

Available on hide_js

The settings of the mesh preview, saved in the display state.

Constructor

new()

Creates the default settings.

Variables

@:value(false)alphaBlend:Bool = false

Renders the preview with alpha blending.

@:value(true)backfaceCulling:Bool = true

Culls the back faces.

@:value(0)bgColor:Int = 0

The background color.

@:value(300)height:Int = 300

The preview height in pixels.

@:value("Sphere")meshPath:String = "Sphere"

The previewed mesh: Sphere, Plane, ScreenFX, or the path of an FBX or prefab.

@:value(false)previewAlpha:Bool = false

Shows the alpha channel.

@:value(null)renderPropsPath:String = null

The path of the render props prefab, or null.

@:value(Alpha)screenFXBlend:PbrBlend = Alpha

For the ScreenFX preview: the blend mode.

@:value(false)screenFXusePrevTarget:Bool = false

For the ScreenFX preview: the screen shader reads the previous target.

@:value(false)shadows:Bool = false

Enables the shadows.

@:value(false)unlit:Bool = false

Renders the preview unlit.

@:value(300)width:Int = 300

The preview width in pixels.
