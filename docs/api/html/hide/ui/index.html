DisplayPosition

The description of a shortcut, for the shortcuts list.

A change recorded in an UndoHistory.

The keyboard shortcuts of an element: actions registered by name, triggered by the key.<name> config entries.

The native menu bar built from an HTML menu description.

QueryHelper

A shortcut to create elements: J(...) is new hide.Element(...).

UndoHistory

The undo and redo history of a view.

View

The base class of the IDE views (tabs): state, config, keys, undo, clipboard, file watches and layout container. A view class is registered with View.register.

ViewOptions

The options of a view class, given to View.register.
